S11 對抗戰陣容搜尋網站

內容：
- index.html：網站入口
- styles.css：版面與手機版樣式
- app.js：搜尋、缺角排除、排序與統計邏輯
- data.js：2026-09-17 對戰資料快照（9,004 場；不含玩家名稱）

直接使用：
1. 解壓縮。
2. 直接開啟 index.html 即可使用。
3. 若要放到靜態網站服務，將整個資料夾內容上傳即可，不需要後端或資料庫。

搜尋邏輯：
- 先排除進攻隊中含「我沒有的角色」的紀錄。
- 對已知的防守位置計算「站位符合」與「角色符合」。
- 預設站位優先；可關閉後提高角色組成的權重。
- 完全相同站位 > 同角色不同站位 > 相近陣容。
- 綜合推薦同時考慮符合度、勝率、Wilson 保守勝率與樣本數，避免 1 勝 0 敗直接排在大量樣本前面。
- 每組進攻隊的統計只採用接近該隊最佳符合度的對戰，避免把差太遠的防守陣容混在一起。
